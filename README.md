# SimpleSSH

iPhone・iPad・Mac・Apple Vision Pro で使える、普段使いに使えるシンプルな SSH ターミナル **SimpleSSH** の
公開ページと、利用者からの問い合わせ窓口。

- サポート: https://asterisoft.github.io/simplessh/
- プライバシーポリシー: https://asterisoft.github.io/simplessh/privacy.html

## 問い合わせ

ご質問・不具合の報告・機能のご要望は [Issues](../../issues) へ。

不具合の報告では、次を書き添えていただけると調査が早い。

- お使いの機種と OS のバージョン
- アプリのバージョン
- 何をしたときに何が起きたか

## このリポジトリについて

**アプリのソースコードは含まない。** 公開ページ（HTML）と問い合わせ窓口だけを置いている。
