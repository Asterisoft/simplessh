SimpleSSH について

SimpleSSH は、サーバの操作・ファイルの受け渡し・画面の操作を 1 つのアプリでまとめて扱う リモート接続クライアントである。SSH での端末操作、SFTP でのファイル転送、 VNC と RDP での画面操作を、同じウィンドウのタブの中で並べて使える。

主な機能

SSH ターミナル

  • パスワード認証と公開鍵認証（Ed25519 / RSA）
  • xterm 互換の端末。Sixel と iTerm2 形式のインライン画像の表示
  • EUC-JP / Shift_JIS の文字コードへの対応
  • 踏み台サーバを経由する多段接続（ProxyJump）
  • ホスト鍵を初回接続時に確認し、以後の変化を検出する
  • Mac では ssh_config から接続先を取り込める

SFTP でのファイル操作

  • アップロード、ダウンロード、移動、削除
  • Markdown の表・画像・HTML・PDF・SVG のその場でのプレビュー
  • よく開く場所のブックマーク登録

VNC と RDP での画面操作

  • SSH と同じタブの中で画面を開ける
  • SSH トンネル経由での接続（画面転送のポートを外部へ開けなくてよい）
  • 日本語を含むクリップボードの双方向共有
  • RDP は NLA 認証と、表示領域に合わせた解像度の追従に対応

そのほか

  • タブをドラッグして落とした位置で、移動するか分割するかが決まる（Mac では画面の外へ落とすと別ウィンドウ）
  • iPhone / iPad ではソフトキーボードの上に Esc・Ctrl・矢印・F1〜F12 などのキー行が出る
  • よく使うコマンドをマクロとして登録し、1 タップで送れる
  • 接続時に自動で流すスクリプトを接続先ごとに設定できる
  • 接続先の情報は iCloud で同期し、秘密鍵とパスワードは iCloud キーチェーンに保存する

よくある質問

接続先の情報や鍵はどこに保存されるのか

接続先の情報はご自身の iCloud（プライベートデータベース）に、パスワードと秘密鍵は iCloud キーチェーンに保存される。開発者がこれらを参照する手段は無い。 詳しくはプライバシーポリシーを参照されたい。

別の端末で登録した接続先が出てこない

同じ Apple アカウントでサインインしていること、および「設定」で iCloud Drive と iCloud キーチェーンが有効になっていることを確認していただきたい。 同期が使えない状態のときは、アプリの一覧の上部にその旨が表示される。

VNC や RDP のポートを外部に開けたくない

接続先の設定で SSH トンネルを経由するようにできる。この場合、外部へ開けるのは SSH のポートだけでよい。

Intel の Mac で使えるか

現在の Mac 版は Apple シリコン専用である。
